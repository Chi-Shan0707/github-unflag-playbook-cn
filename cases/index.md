## 提交案例

1. 复制 [GitHub 源码模板](https://github.com/Chi-Shan0707/github-unflag-playbook-cn/blob/main/cases/template.md)，或先阅读[网页版模板]({{ '/cases/template/' | relative_url }})
2. 填写经历，并移除邮箱、工单编号等敏感内容
3. 提交 PR，文件命名为 `<你的用户名>.md`
4. 在 PR 中确认你同意公开这些信息

也可以使用[案例 Issue 表单](https://github.com/Chi-Shan0707/github-unflag-playbook-cn/issues/new?template=case-report.yml)，由维护者协助整理。

<section class="policy-note">
  <h2>隐私与外链</h2>
  <ul>
    <li>案例仅在当事人明确同意后公开，并可随时申请修改或删除。</li>
    <li>邮箱、工单编号和其他敏感信息在收录前应当脱敏。</li>
    <li>外链在收录时检查，并在隔离的新窗口中打开；第三方内容仍可能变化。</li>
