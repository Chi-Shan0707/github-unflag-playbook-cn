## 如何提交你的案例

1. 打开案例模板：推荐复制 [GitHub 源码版](https://github.com/Chi-Shan0707/github-unflag-playbook-cn/blob/main/cases/template.md)，也可以先阅读[网页版模板]({{ '/cases/template/' | relative_url }})
2. 填写你的信息，并移除邮箱、工单编号等敏感内容
3. 提交 PR，文件命名为 `<你的用户名>.md`
4. 在 PR 中确认你同意公开这些信息

如果你不想提交 PR，也可以使用[案例 Issue 表单](https://github.com/Chi-Shan0707/github-unflag-playbook-cn/issues/new?template=case-report.yml)，维护者会帮你整理。
